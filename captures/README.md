# Captures Directory

This folder stores all captured photos from the application.

Photos are automatically saved here when you click the "Capture Photo" button in the application.

## File Naming Convention

Captured images are saved with timestamps:
- Format: `capture_YYYYMMDD_HHMMSS.jpg`
- Example: `capture_20231119_143052.jpg`

## Features

- All captured images include face detection boxes
- Age, gender, and emotion labels are drawn on the images
- Multiple faces are captured if detected
- Images are saved in JPEG format

## Note

This folder is automatically created when you run the application for the first time.
